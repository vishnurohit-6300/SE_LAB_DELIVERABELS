## Architecture selected

The project uses a **Layered Architecture** with a Presentation Layer, Business Layer, and Data Layer. The Business Layer contains Tournament Management, Team Registration, Bracket Management, Match & Standings, and Notification components. The Data Layer contains the Database component.
